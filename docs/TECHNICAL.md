# 기술 설명

| 항목 | 내용 |
|---|---|
| 디스크 | DVD ISO. 루트에 CRI CVM 5개(`JPN/BIN/MOV/ADXJ/ETC.CVM`), `SLPM_654.05`, `CRSDAT.MRG` |
| CVM | `CVMH` 헤더 + `ZONE` + 내부 ISO9660(+0x1800). 크기 필드 3곳(헤더 0x20, ZONE+8, ZONE+0x34) 갱신. `ETC.CVM` 은 빈 공간이라 커진 CVM 의 재배치 공간으로 사용 가능 |
| 압축 | `CRICMP 2.10`: 16비트 빅엔디안 플래그(LSB부터), 토큰 16비트 — 리터럴 2바이트 / `w&0xF000==0` 이면 직전 바이트 `w+3`회 채움 / 그 외 길이 `(w>>12)+2`, 거리 `w&0xFFF` 복사. 해제·재압축 직접 구현 |
| 텍스트 | `JPN/BOOTDAT.CMP` 안 MRG → 문자열 표 11개(오프셋 표 + SJIS). 접두 6자 `PP A FFF` = 우선순위 / 표시 속성 / 얼굴 번호 |
| 음성 자막 | `NAVI_PlayVoice(종류, 번호)` 의 번호가 문자열 표 번호와 같음. `NAVI_DispNarrationExec` 는 접두 표시 속성 bit0 이 켜진 대사만 창에 그림 → 음성 대사의 속성을 `0`→`1` 로 바꿔 자막 활성화 |
| 글꼴 | `CRSDAT.MRG` 안 Sony FNT(20×20 4bpp, 5,358자, JIS 행 순서 94×57). 한글 2,350자를 JIS 16~40행(SJIS 0x889F~)에 배치 |
| 텍스처 | TIM2 4/8bpp 는 PSMCT32 업로드 스위즐. 큰 그림은 업로드 폭 = 너비/2, 높이 64 이하 작은 그림은 업로드 폭 16/32 등 → 재스위즐 결과가 원본과 바이트 일치하는 해석을 선택 |
| 실행파일 | 심볼 테이블 포함. 시스템 메시지는 원래 자리 안에서 교체 |
| 동영상 | SFD(MPEG-1 시스템, MPEG-2 영상 + ADX). 4편 모두 대사 음성 없음 |
