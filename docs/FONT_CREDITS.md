# 글꼴 출처

- 게임 글꼴(`CRSDAT.MRG` 안의 Sony FNT 20×20 4bpp, 5,358칸)의 한글 2,350자: NanumSquare Neo dEb(ExtraBold) 17px, 4배 확대 렌더 후 축소해 원본과 같은 흰 본체 + 회색 외곽선 단계로 변환 (`tools/font.py`).
- 글자 그림(메뉴·조작 설명·제목 등): NanumSquare Neo cBd/dEb/eHv, 원본 팔레트로 양자화 (`tools/texedit.py`).
